# U200 demo media

[Play / download the demo](fiaccel_u200_demo.mp4).

MP4: 1920×1080, 60 fps, 12 seconds. Left: 30 fps source. Right: trained-model
U200 interpolation encoded at 60 fps. Normal playback is followed by 0.25×
slow motion. The source is a two-second excerpt; replay does not add source frames.

the CC BY 3.0 attribution above.

[`demo_preview.gif`](demo_preview.gif) is a looping 960×540, 15 fps,
six-second excerpt for the project README. Use the MP4 for full 60 fps playback.

film footage and appears in the [board guide](../hardware/u200/README.md).
